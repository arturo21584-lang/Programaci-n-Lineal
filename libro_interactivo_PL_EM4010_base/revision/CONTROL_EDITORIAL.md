# Protocolo de revisión editorial

Un capítulo **no** está listo para publicar si queda alguna casilla sin verificar.

- [ ] Consultamos realmente las fuentes atribuidas.
- [ ] Comprobamos metadatos de cada referencia y páginas citadas.
- [ ] Comprobamos hipótesis, definiciones y demostraciones.
- [ ] Resolvimos independientemente los ejemplos y ejercicios.
- [ ] Verificamos todos los controles y estados relevantes de las interacciones.
- [ ] Comprobamos originalidad, atribución y derechos de las figuras y documentos.
- [ ] Revisamos legibilidad, accesibilidad y presentación móvil.
- [ ] Aprobación editorial expresa.

No introducir datos de referencia supuestos. Si falta el libro o una página, marcar como pendiente.
